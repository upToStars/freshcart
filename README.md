# FreshCart — React shopping cart demo

A practice ecommerce interface built with React and the public [DummyJSON Products API](https://dummyjson.com/docs/products).

## Features
- Load more products while scrolling (IntersectionObserver)
- Search by product name and filter by category
- Add items to cart, change quantities, and calculate total
- Multi-step demonstration checkout (delivery, payment choice, summary)

**Note:** This is a frontend demo. It does not process real orders or payments.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Technology
React, Vite, JavaScript, CSS, DummyJSON API.

Adapted from an earlier learning exercise, with a standalone entry point and basic styling for portfolio presentation.
